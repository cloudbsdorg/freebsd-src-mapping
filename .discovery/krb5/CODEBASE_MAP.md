# krb5/ — Kerberos 5 Build Configuration Codebase Map

**Path:** `krb5/`
**Purpose:** Build directory for Kerberos 5

## Overview

The krb5 directory is a build-related directory for Kerberos 5 support.

## Key Points

- Build system for Kerberos 5
- Uses Heimdal from `crypto/heimdal/`
- or MIT Kerberos from `contrib/heimdal/`

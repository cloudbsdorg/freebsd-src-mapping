# sys/dev/sdhci/ — SDHCI MMC Driver Codebase Map

**Path:** `sys/dev/sdhci/`
**Purpose:** Secure Digital Host Controller Interface

## Overview

The sdhci driver supports SD/MMC card hosts.

## Key Files

| File | Purpose |
|------|---------|
| `sdhci.c` | Main |
| `sdhcivar.h` | Variables |

## Features

- SD, SDHC, SDXC support
- MMC, eMMC support
- High speed mode
- UHS-I mode

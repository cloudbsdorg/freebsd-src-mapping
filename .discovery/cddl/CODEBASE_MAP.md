# cddl/ — CDDL Licensed Software Codebase Map

**Path:** `cddl/`
**Purpose:** Software under CDDL license (DTrace, ZFS)

## Overview

The cddl directory contains DTrace and ZFS, licensed under CDDL.

## DTrace

| Directory | Purpose |
|-----------|---------|
| `dtrace/` | DTrace user tools |
| `libdtrace/` | DTrace library |

### DTrace Components

- `dtrace/` - Command-line tools
- `libdtrace/` - libdtrace library
- Provider definitions

## ZFS

| Directory | Purpose |
|-----------|---------|
| `zfs/` | ZFS filesystem |
| `libzfs/` | ZFS administrative library |

### ZFS Components

- ZFS kernel module
- ZFS on-disk format
- libzfs for administration

## CDDL License

CDDL (Common Development and Distribution License) is incompatible with GPL but allows code sharing withillumos/OpenSolaris.
